# Case Note

推理ゲームやマーダーミステリーで得た情報を書き留め、キーワード・つながり・時系列を整理する個人用Webアプリです。メモを読み返しながら、自分で手がかりをつなげていきます。

**[アプリを開く](https://ineko0402.github.io/case-note/)**

PC・スマホのブラウザで利用できます。アカウント登録は不要です。データは使用中のブラウザに保存され、端末間の自動同期はありません。

## はじめに

1. **メモ**で、手がかりを入力・貼り付けて追加します。
2. 名前・番号・場所などを**キーワード**にして、分類します。
3. 関連メモを読みながら、キーワード同士を**つなげます**。
4. **つながり**で関係を見渡し、必要なメモを時系列に並べます。

ゲームを終えたら「データ管理」からバックアップを保存できます。次のゲームを始めるときは、データを消去して初期状態に戻せます。

## ホーム画面に追加・オフライン利用

フッターの「アプリをインストール」から、対応ブラウザの確認画面またはインストール手順を開けます。アプリとして起動している間はこのボタンを表示しません。

Case NoteはPWAとしてホーム画面に追加できます。アイコンは、琥珀色の手がかりから2枚の資料へつながるC案を採用しています。

- **iPhone**：Safariでアプリを開き、共有メニューから「ホーム画面に追加」を選びます。「Webアプリとして開く」が表示される場合はオンにします。
- **Android・PC**：対応ブラウザの「アプリをインストール」または「ホーム画面に追加」を使います。表示名や場所はブラウザによって異なります。

初回はオンラインで開いてください。画面と必要なファイルの保存が完了した後は、オフラインでもメモの入力・編集・整理ができます。インストールせずブラウザで使う場合も同じです。

更新はバックグラウンドで準備し、開いているCase Noteのタブ・アプリをすべて閉じて、再度開いたときに反映します。入力中の画面は自動で再読み込みしません。

メモの保存には引き続きIndexedDBを使います。ブラウザとホーム画面のアプリでデータが引き継がれるかは利用環境によるため、追加前にJSONバックアップを保存してください。ホーム画面のアプリが空の場合は、そのバックアップを読み込めます。オフライン用ファイルの保存はメモのバックアップの代わりにはなりません。

アイコンの編集用SVGとPNGは`public/icons/`にあります。主色はモスグリーン`#465E49`、紙色はアイボリー`#F5F3EA`、注目する手がかりは琥珀色`#C49A50`です。

## 3つの画面

| 画面 | 使い方 |
| --- | --- |
| メモ | 情報を書き留める画面です。新規メモはここで追加し、登録順の古い順／新しい順で読み返せます。 |
| キーワード | 分類・名前変更・統合・並べ替えを行う画面です。キーワードを選ぶと関連メモに絞り込みます。PCではもう一度選ぶとすべてのメモに戻り、スマホでは「すべてのメモを表示」で戻します。 |
| つながり | 「関係」でキーワードのつながりを見渡し、「時系列」でタイムラインを確認する画面です。 |

既存メモは各画面から編集できます。PC・スマホとも「閉じる」では保存せず、未保存文は同じメモを再編集すると戻ります。画面切替後も戻せますが、再読み込み・データ復元・全消去では破棄されます。Ctrl/Cmd＋Enterで追加・保存できます。キーワード画面のメモは整理用に並べ替えられ、「メモ」画面の登録順とは独立しています。

キーワード一覧は見出し横の「一覧を隠す」で閉じ、「キーワード一覧を表示」で戻せます。スマホではキーワードを押すと下部の操作バーを開きます。操作バーを閉じても、見ているメモや絞り込みは維持します。

## メモとキーワード

キーワードにする方法は3つあります。

- **候補をタップする**：入力欄の下に表示される候補を押します。未登録候補は同じ語の出現箇所をまとめて変換し、登録済み候補は1か所ずつ変換します。
- **文章を選択する**：入力欄の文章を選択し、表示される操作からキーワードにします。
- **直接入力する**：`*キーワード` の記法で書きます。

```text
*0900 *食堂 で *6 が *太郎 と話していた。
```

`*` から次の空白・改行までがキーワードです。前後に空白を入れてください。半角・全角スペースを使えます。番号・名前・時刻の分類は自動判定せず、自分で設定します。

入力欄の下でキーワードと候補を確認でき、スペースや表記を直すと候補も更新されます。候補を押した時点では本文を書き換えるだけなので、最後に「追加／保存」でメモを確定します。

PCの新規入力はメモ画面の入力欄、スマホの新規入力・編集はモーダルを使います。モーダルの下部操作は「閉じる」「追加／保存」です。「閉じる」では新規下書きを残します。PCでは Ctrl+Enter、Macでは Command+Enter でも追加・保存できます。

スマホでは、メモの本文や日時をタップすると画面下に操作バーが出ます。キーワードをタップした場合は、そのキーワードの操作へ切り替わります。「操作を閉じる」では見ているメモや絞り込みを戻しません。すべてのメモに戻るときは、表示を戻すボタンを使います。

## キーワードの整理

PCは選択したキーワードの「編集」、スマホは下の操作バーの「分類」「その他」から、分類・名前変更・統合を行います。名前変更と統合は、メモ中のキーワードとつながりなどの関連データにも反映します。統合先の候補は、元の語を含む名前を優先します。直後の「元に戻す」は、別のデータ変更をするまで使えます。

初期分類は「未分類」「ナンバー」「人物」「場所」「アイテム」「時間」「その他」です。「分類設定」で追加・名前変更・並べ替え・削除ができます。「未分類」は固定です。

- **未分類の「まとめて分類」**：複数のキーワードを選んで分類します。未分類が残っていれば、分類後も画面を閉じずに続けられます。
- **ナンバーの「番号をまとめて追加」**：指定範囲の未登録の番号を追加します。
- **時間・ナンバーのソート**：時間は `0900` や `09:00`、ナンバーは数字だけのキーワードを順に並べられます。

分類は折りたたみ可能です。キーワード・分類はハンドルで並べ替えられます。整理順のメモは、PCではハンドルと上下ボタン、スマホでは操作バーの「その他」から上下移動できます。

スマホではメモの操作バーの「その他」から削除できます。つながり画面の関連メモは表示／非表示を切り替えられ、表示すると関係一覧の下に並びます。

## つなげる・つながりを見る

キーワードを選んで「つなげる」を押すと、相手の選び方を選べます。

スマホのキーワード操作バーには、直接つながっている相手を4件まで表示します。チップの「仮／確定」と枠線で状態を確認でき、「すべて見る」で全件と長い名前を確認・編集できます。相手のチップを押すと操作対象だけを切り替え、関連メモの絞り込みは維持します。

- **一覧から選ぶ**：キーワードの候補一覧で相手を選びます。
- **メモから選ぶ**：関連メモを読みながら、本文中のキーワードを選びます。

どちらも分類・検索で絞り込め、同じメモで使われた相手を強調します。相手を選んで「仮につなげる」で登録します。続けてつなげたり、直前に追加したつながりを取り消したりできます。キーワード同士のドラッグでも仮につなげられます。

登録したつながりの「仮／確定」を押すと、状態が切り替わります。仮は薄い色と破線、確定は濃い色と実線で表示します。隣の「⋯」から関係の種類を変更したり、つながりを外したりできます。編集メニューはPCではポップアップ、スマホではモーダルとして表示します。

複数の相手とつなげられますが、別の相手への関係を自動で推測・生成することはありません。「同一人物」の確定はナンバーと人物の1対1です。すでに確定した相手がいる場合は、変更前に確認します。

「つながり」画面の「関係」では、登録済みのつながりを自動で一覧表示します。同一人物として確定した番号と名前は1枚のカードにまとまります。分類・検索で絞り込み、関連メモから根拠を読み返せます。

## 時系列

「つながり」→「時系列」でタイムラインを表示します。時間を含むメモがすべて自動で載るわけではなく、載せたいメモを選んで追加します。

キーワード画面のメモの時計アイコン、または時系列の「メモを選んで追加」から設定できます。「時間」に分類したキーワードを時刻候補として使い、複数ある場合は基準時刻を選べます。時間のないメモも時刻不明として追加できます。

時刻順に表示し、同時刻はメモの整理順、時刻不明は末尾になります。本文を編集しても基準時刻は維持します。時計アイコンで設定を変更でき、タイムラインから外してもメモは残ります。

本文のキーワードを押すと関連するメモに絞り込み、「すべて表示」でキーワードと検索の絞り込みを解除します。

## 保存とバックアップ

データは使用中のブラウザのIndexedDBに保存します。ブラウザや端末を変えても自動では引き継がれません。ブラウザの保存データを削除すると、アプリのデータも消えます。

画面下の「データ管理」で、次の操作ができます。

| 操作 | 内容 |
| --- | --- |
| ゲームタイトル | タイトルを自動保存し、バックアップの内容とファイル名に含めます。未設定でも使えます。 |
| バックアップを保存 | メモ・分類・つながり・タイムライン・新規下書きなどをJSONファイルに保存します。 |
| バックアップから復元 | JSONファイルの内容で現在のデータを置き換えます。追加・合算ではありません。 |
| すべてのデータを消去 | ゲームタイトルを含むデータを消去し、分類を初期状態に戻します。 |

復元・消去の前に、現在のバックアップを保存できます。編集中のメモは先に「保存」してください。バックアップはv5形式で、旧v1〜v4形式も読み込めます。廃止した「まとまり」と旧関係図の配置データは読み込み時に破棄し、その後の保存・バックアップには含めません。メモ・分類・つながり・タイムラインは引き継ぎます。

## 開発

Node.js 24を使用します。

```sh
npm ci
npm run dev
```

テストと公開用ビルド：

```sh
npm test
npm run build
```

## GitHub Pagesへの公開

リポジトリの **Settings → Pages → Source** で **GitHub Actions** を選びます。

[公開ワークフロー](.github/workflows/pages.yml)が、`main`へのpush時にテスト・ビルド・公開を行います。プルリクエストではテストとビルドを行います。

仕様・設計判断と既知の確認事項は [PROJECT_STATE.md](PROJECT_STATE.md) にまとめています。
