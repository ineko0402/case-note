# Case Note

推理ゲームのメモとキーワードを整理する、個人用のWebアプリです。

## 使い方

メモに `*1810 *食堂 *6 気になったこと` のように書き、追加します。
`*` から次の空白までをキーワードとして扱います。半角・全角スペース、改行で区切れます。キーワードの前にも空白を入れてください。
番号・名前・時刻の意味は自動判定しません。キーワード画面で分類すると、同じキーワードを含むすべてのメモに反映されます。

- メモの追加・編集・削除、本文検索
- キーワードによる絞り込み、登場するメモ件数の表示
- 未分類／ナンバー／人物／場所／アイテム／時間／その他への分類
- IndexedDBへの保存（下書きも保存）
- JSONバックアップの保存・読み込み（現在のデータを置き換え）

メモは利用中のブラウザに保存します。端末間の自動同期はありません。ブラウザのデータ削除に備え、定期的にバックアップを保存してください。
Ctrl+Enter（MacではCommand+Enter）でメモを追加できます。

## 開発

Node.js 24を使用します。

```sh
npm ci
npm run dev
npm test
npm run build
```

## GitHub Pages

Settings → Pages → Build and deployment → Sourceで **GitHub Actions** を選択します。
mainへのpush時に `.github/workflows/pages.yml` がテスト・ビルド・公開を行います。PRではテストとビルドのみ実行します。
公開URLは https://ineko0402.github.io/case-note/ です。
