# Case Note

推理ゲームのメモとキーワードを整理する、個人用のWebアプリです。

## 使い方

メモに `*1810 *食堂 *6 気になったこと` のように書き、追加します。
`*` から次の空白までをキーワードとして扱います。半角・全角スペース、改行で区切れます。キーワードの前にも空白を入れてください。
番号・名前・時刻の意味は自動判定しません。キーワード画面で分類すると、同じキーワードを含むすべてのメモに反映されます。

- メモの追加・編集・削除、本文検索
- 入力・編集中の文字選択からキーワード化（登録済み表示、分割・空白除去）
- キーワードによる絞り込み、登場するメモ件数の表示
- 分類内キーワードの並べ替え、分類の開閉
- 分類設定で追加・名前変更・並べ替え・削除（未分類は固定）
- 未分類／ナンバー／人物／場所／アイテム／時間／その他への分類
- IndexedDBへの保存（下書きも保存）
- JSONバックアップの保存・読み込み（現在のデータを置き換え）

メモは利用中のブラウザに保存します。端末間の自動同期はありません。ブラウザのデータ削除に備え、定期的にバックアップを保存してください。
Ctrl+Enter（MacではCommand+Enter）でメモを追加できます。

## 開発

Node.js 24を使用します。

```sh
npm ci
npm run dev
npm test
npm run build
```

## 今後の予定

関係図、カードの自由配置、手動で並べるタイムライン。番号と氏名は別々のカードとして保持し、関係線で結びます。

旧形式（v1）のバックアップも読み込めます。新しいバックアップには並び順と分類の開閉状態も含みます。

メモタブは登録順、キーワードタブは手動の整理順で表示します。キーワードで絞り込んだときも整理順は共通です。ハンドル（⠿）をドラッグし、「ここに移動」の目印へドロップしてください。上下ボタンでも並べ替えできます。長いキーワードも省略せず、必要に応じて折り返して表示します。

タブは常に表示され、キーワード一覧とメモ領域は独立してスクロールします。タブ切り替えではスクロール位置を保持します（ページ再読み込みではリセット）。長いキーワードも省略せず表示し、必要な場合に折り返します。

## 結ぶ

キーワードを選び、詳細欄の「結ぶ」から相手を選びます。左一覧、メモ内のキーワード、検索付き候補一覧から選択できます。結びは最初は「仮」で、「確定にする」「仮に戻す」「解除」で変更できます。ラベルや向きはなく、複数の相手と結べます。結んでも語を統合せず、他の関係を自動で作ることもありません。

まとまりの操作・表示は現在提供していません。以前のまとまりデータはバックアップ互換のため保持します。

v3バックアップには結びとまとまりを含みます。以前のv1/v2バックアップも読み込めます。

## 関係図

「関係図」タブで左のキーワードからカードを置き、自由に移動できます。カードの接続点から相手の接続点へ線を引くと「仮」の結びを作ります。メモ・キーワード一覧の「結ぶ」と同じデータを使うため、両端を配置すると既存の結びも表示されます。

仮は薄い破線、確定は太い実線です。線を選ぶと仮／確定の変更・解除ができます。カードを選ぶと関連メモを開いたり図から外したりできます。図から外しても、メモと結びは残ります。空白をドラッグして表示位置を動かし、拡大・縮小・全体表示のボタンで表示を調整できます。

位置・表示倍率は保存とバックアップの対象です。v4バックアップを使用し、旧v1/v2/v3も引き継げます。

## メモを読みながら整理する

キーワードタブでは、選択中のキーワードと仮・確定の結びを右上に固定表示します。上部の「キーワード／関係図」タブを切り替えても左一覧と選択は共通です。関係図の横で関連メモを読めます。「メモを閉じる／表示」で図の広さを調整できます。図には選択語、関連メモ内の語、直接結んだ相手の配置済みカードを表示します。「すべてのメモ」で絞り込みを解除できます。

メモタブは登録順のままです。本文中のキーワードを押すと、その語と結んだ相手を強調します。もう一度押すか「強調を解除」で戻せます。新規入力・編集欄のすぐ上には、入力中のキーワードを重複なしのチップで表示します。

未分類の見出しにある「まとめて分類」で複数の語を選び、カテゴリを一括設定できます。「未分類をすべて選択」も使えます。分類済みの語は上書きしません。設定後も未分類が残る場合は、選択をクリアして画面を開いたままにします。すべて分類すると閉じます。

関係図はメモ欄を閉じて開きます。「メモを表示」で右側にメモを重ねて表示できます。「一覧を閉じる」で左のキーワード一覧も閉じて図を広く使えます。固定欄の結びは状態（仮／確定）から変更・解除を開けます。

一括分類では横並びのキーワードボタンを押して選びます。下の「選択内容」枠で確認し、分類先を選んで「まとめて設定」を実行します。選択内容の語を押すと個別に外せます。

広い画面では整理画面の右列を画面上部から使い、メモや図の表示領域を確保します。分類見出しは「分類」、キーワードは `*` と淡い背景で区別します。未分類がない場合は一括分類ボタンを表示しません。

### キーワードの名前変更
キーワードを選び「名前を変更」から、新しい名前と対象メモ件数を確認して実行します。明示キーワードだけが置き換わり、分類・結び・まとまり・関係図の位置は引き継がれます。登録済みへの統合は未対応です。直後の「元に戻す」は、別のデータ変更をするまで利用できます。メモ編集中や結ぶ相手を選択中は名前変更と取り消しを停止します。

### 分類のソートと番号の一括追加
「時間」はHHMMまたはHH:MMの時刻順、「ナンバー」は数字だけのキーワードを数値順に並べられます。ボタンを押したときだけ並べ替え、同値と解釈できない表記は元の順序を維持します。解釈できない表記は分類の末尾になります。
ナンバーの見出しにある「番号をまとめて追加」では開始・終了（0以上、1000個以内）を指定して候補を確認し、未登録の番号を「ナンバー」へ登録します。既存キーワードは分類を変えずスキップします。メモ0件でも保存・バックアップ・名前変更・結び・関係図に利用できます。

### タイムライン
各メモの「タイムラインに表示」を開いてチェックすると、タイムラインタブへ追加されます。「時間」分類の時刻が1つなら自動採用し、複数なら候補ボタンまたは基準時刻欄で指定できます。時刻不明は末尾、同時刻は整理順になります。追加を外してもメモは残り、登録順・整理順は変更しません。基準時刻は設定時の値を保持し、本文の時刻を編集したときは必要に応じて設定し直してください。
タイムラインの各メモは「編集」からその場で修正できます。入力中のキーワード一覧とキーワード登録に対応し、保存・キャンセルまたはCtrl/Cmd+Enterで保存します。本文の時刻を変えても基準時刻は維持されるため、必要に応じて保存後に変更してください。


## メモから関係図
各メモの「このメモを図で見る」からキーワードを確認して配置。すべて／一部を選択でき、別メモの「図に追加」で比較可能。図の対象メモを上部に表示。既存カードの位置を維持し、追加カードをグリッドに配置。メモの共起だけでは線を作らない。結び・カード配置は全体と共通、対象メモと表示範囲は画面内のみ。


## タイムライン一括追加
タイムラインから未登録メモを複数選択。検索・表示中をすべて選択・選択をクリア・基準時刻候補・直接指定に対応。1時刻なら初期値、複数／空欄は不明。既存設定を変更しない。


## キーワード統合
既存キーワードを統合先に選び、対象件数と分類を確認して実行。原文の明示キーワード・下書き・分類・順序・登録・結び・まとまり・図に反映。自己結びを除去し、重複は確定優先。統合先カード位置を優先。選んだ分類以外のまとまりから外す。直後の取り消しは他のデータ変更まで有効。

### データ管理
フッターの「データ管理」にバックアップ保存・バックアップから復元・全消去をまとめています。復元前は現在とファイル内の件数を確認し、内容を置き換えます。消去前にもバックアップを保存できます。全消去はメモ・下書き・登録キーワード・分類・結び・まとまり・関係図・タイムラインを初期状態に戻し、編集中の未保存文章も破棄します。復元と消去は保存成功後に画面へ反映し、失敗した場合は現在のデータを保持します。

### 同一人物の結び
ナンバーと人物を結んだ後、結びの操作メニューで種類を「同一人物」にできます。仮候補は複数持てますが、確定は各キーワードにつき1人だけです。別の相手が確定済みの場合は、その結びを仮に戻すことを確認して変更します。種類未指定の既存の結びは「関係あり」として扱います。名前変更・分類変更で判定は保持されます。キーワード統合で同一人物の確定が重複する場合は、先に不要な確定を仮に戻してください。人物カードのまとめ表示は次の段階です。

### 関係図の人物カード
同一人物として確定した2つのキーワードは、関係図で1枚にまとめて表示します。どちらか一方を図に置けば両方の名前が表示され、関連アイテムとメモ件数は両方から集めて重複を除きます。アイテムは「関連」であり、現在の所持を断定しません。関連メモを開くと両方のキーワードのメモを表示します。人物カードは内部のキーワード統合ではなく表示上のまとめです。移動すると両方の保存済み位置を同じ距離だけ動かし、同一人物を仮に戻すと元の別カード表示に戻ります。「図から外す」は両方の配置を外し、メモと結びは残します。

メモとタイムラインはメモタブ内の切り替えで表示します。登録順のメモは「古い順／新しい順」を選べます。表示だけを切り替え、手動の整理順やタイムライン順は変更しません。保存状態はフッターに表示します。

入力欄のすぐ上に、入力中のキーワードを重複なしで横並びに表示します。キーワードがなければ一覧を非表示にします。入力欄は右下のハンドルで高さを調整でき、調整した高さはこのブラウザに保存します。選択した文章の登録操作は入力欄の直前に表示します。

## タイムラインのキーワード絞り込み
本文中のキーワードをクリックすると、そのキーワードを含むタイムラインのメモに絞り込みます。確定した同一人物の番号・名前も対象に含めます。選択語は強調表示し、同じ語を再クリックするとキーワードの絞り込みを解除します。「すべて表示」はキーワードと検索文字を両方リセットします。時刻順を維持し、編集中のメモは絞り込みに関わらず表示します。

## つながり一覧（関係図を置き換え）
手動配置の関係図タブを「つながり」に変更。全登録キーワードと結びからカードを自動生成し、図への追加は不要。確定した同一人物の番号と氏名は一枚に統合。直接結んだ相手を分類別に表示し、仮・確定を区別する。人物・ナンバーが初期表示で、アイテムなど任意の分類またはすべてへ切替可能。相手・関連メモボタンからメモを開ける。旧関係図の位置データはバックアップ互換のため保持。
