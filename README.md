# Case Note

推理ゲームの情報を記録し、キーワードとつながりを整理する個人用Webアプリです。

## 3つの画面

- **メモ**：情報を書き留めます。新規メモの追加はこの画面だけで行います。PCは入力欄、スマホは「新しいメモ」のモーダルを使います。登録順を古い順／新しい順に切り替えられます。
- **キーワード**：分類・名前変更・統合・並べ替え・つなげる操作を行います。語を選ぶと関連メモを表示し、もう一度選ぶとすべてのメモに戻ります。
- **つながり**：「関係」で人物や物のつながりを見渡し、「時系列」でタイムラインを表示します。確定した同一人物の番号と名前は一枚のカードにまとまります。

常設の「＋メモ」は設けていません。既存メモの編集は各画面からできます。

## メモとキーワード化

`*1810 *食堂 *6 気になったこと` のように書けます。`*` から次の空白・改行までがキーワードです。キーワードの前にも空白を入れてください。半角・全角スペースを使えます。番号・名前・時刻の意味を自動判定しません。

文章を選択してキーワードにする操作も使えます。入力欄の下にはキーワードと候補をコンパクトに表示します。
登録候補のボタンを押すと、その語を本文中のキーワードにできます。同じ候補の語が複数ある場合はまとめて変換します。メモの追加・保存は別に行います。

新規入力・編集モーダルの下部操作は「閉じる」と「追加／保存」です。キーワード化は入力欄の下の候補をタップして行います。スペースや表記は入力欄で直せ、候補も入力に合わせて更新されます。文章を選択してキーワードにする操作も残しています。

「閉じる」では新規下書きを残します。既存メモの編集は「保存」で反映します。Ctrl+Enter（MacはCommand+Enter）で追加・保存できます。

## キーワードの整理

選択したキーワードの「編集」から分類・名前変更・統合を行います。「つなげる」では一覧から選ぶ方法とメモから選ぶ方法を選べます。つながりの「仮／確定」はクリックで切り替えられます。同一人物の確定に競合があるときは確認を表示します。「⋯」では関係の種類の変更と解除ができます。編集メニューはPCではポップアップ、スマホではモーダルとして表示します。

分類は未分類／ナンバー／人物／場所／アイテム／時間／その他を初期値とし、分類設定で追加・名前変更・並べ替え・削除できます。未分類は固定です。長いキーワードは必要に応じて折り返します。

未分類の「まとめて分類」で複数語を一括設定できます。未分類が残ると画面を継続します。ナンバーの「番号をまとめて追加」は未登録の数字を登録し、既存語の分類は変えません。「時間」はHHMMまたはHH:MM、「ナンバー」は数字だけの語をソートできます。

キーワードタブのメモは整理順です。ハンドル（⠿）または上下ボタンで並べ替えます。登録順とは独立しています。

名前変更と統合は明示キーワード・関連データを更新します。統合先は元の語を含む名前を優先します。直後の「元に戻す」は、別のデータ変更をするまで利用できます。

## つなげる・つながり

「一覧からつなげる」はモーダルで相手を選び、「メモからつなげる」は本文を読みながら相手を選びます。分類・検索で絞り込め、同じメモで使った相手を強調します。相手を選んで「仮につなげる」で実行し、続けてつなげたり直前の新規つながりを取り消したりできます。キーワード同士のドラッグでも仮につなげられます。

つながりは仮／確定を区別します。複数の相手とつなげられ、他の関係を自動生成しません。同一人物の確定は番号と人物の1対1です。関係一覧の分類・検索と関連メモで根拠を確認できます。旧関係図の自由配置とまとまり操作は現在提供していませんが、古いデータをバックアップ互換のため保持します。

## 時系列

「つながり」→「時系列」にタイムラインを表示します。キーワードタブのメモの時計、または時系列の「メモを選んで追加」から載せるメモを選びます。複数の時刻がある場合は基準時刻を選び、時刻不明は末尾、同時刻は整理順に表示します。本文を編集しても基準時刻は維持します。時計から変更でき、タイムラインから外してもメモは残ります。

本文のキーワードを押すと関連するメモに絞り込み、「すべて表示」でキーワードと検索を解除します。

## スマホのスクロール

通常画面はページ全体を縦にスクロールし、ヘッダー・フッターも一緒に動きます。本文と操作欄は画面内の幅に収めます。入力モーダルはタイトル・下部ボタンを固定し、中央をスクロールします。長文は入力欄内でもスクロールできます。メモからつなげる専用モードは、操作欄と候補を使う既存構成を維持します。

## 保存とバックアップ

メモは利用中のブラウザのIndexedDBに保存します。端末間の自動同期はありません。「データ管理」でJSONバックアップの保存・復元・全消去ができます。復元は現在のデータを置き換えます。v4形式を使用し、旧v1／v2／v3も読み込めます。

