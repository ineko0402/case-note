# Case Note

推理ゲームのメモとキーワードを整理する、個人用のWebアプリです。

## 使い方

メモに `*1810 *食堂 *6 気になったこと` のように書き、追加します。
`*` から次の空白までをキーワードとして扱います。半角・全角スペース、改行で区切れます。キーワードの前にも空白を入れてください。
番号・名前・時刻の意味は自動判定しません。キーワード画面で分類すると、同じキーワードを含むすべてのメモに反映されます。

- メモの追加・編集・削除、本文検索
- 入力・編集中の文字選択からキーワード化（登録済み表示、分割・空白除去）
- キーワードによる絞り込み、登場するメモ件数の表示
- 分類内キーワードの並べ替え、分類の開閉
- 分類設定で追加・名前変更・並べ替え・削除（未分類は固定）
- 未分類／ナンバー／人物／場所／アイテム／時間／その他への分類
- IndexedDBへの保存（下書きも保存）
- JSONバックアップの保存・読み込み（現在のデータを置き換え）

メモは利用中のブラウザに保存します。端末間の自動同期はありません。ブラウザのデータ削除に備え、定期的にバックアップを保存してください。
Ctrl+Enter（MacではCommand+Enter）でメモを追加できます。

## 開発

Node.js 24を使用します。

```sh
npm ci
npm run dev
npm test
npm run build
```

## GitHub Pages

mainへのpush時に `.github/workflows/pages.yml` がテスト・ビルド・公開を行います。PRではテストとビルドのみ実行します。

## 今後の予定

関係図、カードの自由配置、手動で並べるタイムライン。番号と氏名は別々のカードとして保持し、関係線で結びます。

旧形式（v1）のバックアップも読み込めます。新しいバックアップには並び順と分類の開閉状態も含みます。

メモタブは登録順、キーワードタブは手動の整理順で表示します。キーワードで絞り込んだときも整理順は共通です。ハンドル（⠿）をドラッグし、「ここに移動」の目印へドロップしてください。上下ボタンでも並べ替えできます。長いキーワードも省略せず、必要に応じて折り返して表示します。

タブは常に表示され、キーワード一覧とメモ領域は独立してスクロールします。タブ切り替えではスクロール位置を保持します（ページ再読み込みではリセット）。長いキーワードも省略せず表示し、必要な場合に折り返します。

## 結ぶ・まとまり

キーワードを選び、詳細欄の「結ぶ」から相手を選びます。左一覧、メモ内のキーワード、検索付き候補一覧から選択できます。結びは最初は「仮」で、「確定にする」「仮に戻す」「解除」で変更できます。ラベルや向きはなく、複数の相手と結べます。結んでも語を統合せず、他の関係を自動で作ることもありません。

カテゴリ見出しの「＋」でカテゴリ内のまとまりを作成・名前変更・削除できます。キーワードの詳細欄で所属を選びます。同じカテゴリ内なら複数のまとまりに入れられます。分類を変えると元のまとまりから外れます。分類を削除するとそのまとまりも削除されますが、キーワードと結びは残ります。

v3バックアップには結びとまとまりを含みます。以前のv1/v2バックアップも読み込めます。

## 関係図

「関係図」タブで左のキーワードからカードを置き、自由に移動できます。カードの接続点から相手の接続点へ線を引くと「仮」の結びを作ります。メモ・キーワード一覧の「結ぶ」と同じデータを使うため、両端を配置すると既存の結びも表示されます。

仮は薄い破線、確定は太い実線です。線を選ぶと仮／確定の変更・解除ができます。カードを選ぶと関連メモを開いたり図から外したりできます。図から外しても、メモと結びは残ります。空白をドラッグして表示位置を動かし、拡大・縮小・全体表示のボタンで表示を調整できます。

位置・表示倍率は保存とバックアップの対象です。v4バックアップを使用し、旧v1/v2/v3も引き継げます。まとまりの枠表示とタイムラインは今後の予定です。

## メモを読みながら整理する

キーワードタブでは、選択中のキーワードと仮・確定の結びを右上に固定表示します。上部の「キーワード／関係図」タブを切り替えても左一覧と選択は共通です。関係図の横で関連メモを読めます。「メモを閉じる／表示」で図の広さを調整できます。図には選択語、関連メモ内の語、直接結んだ相手の配置済みカードを表示します。「すべてのメモ」で絞り込みを解除できます。

メモタブは登録順のままです。本文中のキーワードを押すと、その語と結んだ相手を強調します。もう一度押すか「強調を解除」で戻せます。新規入力・編集欄の上には即時プレビューを表示し、キーワード部分を強調します。

「未分類をまとめて分類」で複数の語を選び、カテゴリを一括設定できます。「未分類をすべて選択」も使えます。分類済みの語は上書きしません。

関係図はメモ欄を閉じて開きます。「メモを表示」で右側にメモを重ねて表示できます。「一覧を閉じる」で左のキーワード一覧も閉じて図を広く使えます。固定欄の結びは状態（仮／確定）から変更・解除を開けます。

一括分類では横並びのキーワードボタンを押して選びます。下の「選択内容」枠で確認し、分類先を選んで「まとめて設定」を実行します。選択内容の語を押すと個別に外せます。

広い画面では整理画面の右列を画面上部から使い、メモや図の表示領域を確保します。分類見出しは「分類」、キーワードは `*` と淡い背景で区別します。未分類がない場合は一括分類ボタンを表示しません。

### キーワードの名前変更
キーワードを選び「名前を変更」から、新しい名前と対象メモ件数を確認して実行します。明示キーワードだけが置き換わり、分類・結び・まとまり・関係図の位置は引き継がれます。登録済みへの統合は未対応です。直後の「元に戻す」は、別のデータ変更をするまで利用できます。メモ編集中や結ぶ相手を選択中は名前変更と取り消しを停止します。

### 分類のソートと番号の一括追加
「時間」はHHMMまたはHH:MMの時刻順、「ナンバー」は数字だけのキーワードを数値順に並べられます。ボタンを押したときだけ並べ替え、同値と解釈できない表記は元の順序を維持します。解釈できない表記は分類の末尾になります。
「番号をまとめて追加」では開始・終了（0以上、1000個以内）を指定して候補を確認し、未登録の番号を「ナンバー」へ登録します。既存キーワードは分類を変えずスキップします。メモ0件でも保存・バックアップ・名前変更・結び・関係図に利用できます。
